# UEX Agent — Features & Chat Examples

A commodity trading and mining location assistant for Star Citizen, powered by UEX Corp API data and optional LLM response generation.

---

## Core Features

### Commodity Trading
Find the best places to buy and sell any commodity across all star systems.

| Example Query | What It Does |
|---|---|
| `Where should I sell Bexalite?` | Available sell locations sorted by price |
| `Where can I buy Laranite?` | Cheapest buy locations with stock info |
| `Buy Laranite on Hurston` | Buy locations filtered to Hurston |
| `Sell Quantanium in Stanton` | Sell locations filtered to Stanton system |


### Price Check
Get current pricing info for any commodity.

| Example Query | What It Does |
|---|---|
| `What's the price of Agricium?` | Current buy/sell prices across terminals |
| `Price of Gold in Pyro` | Prices filtered to a specific system |

### Price History
View actual timestamped UEX reports for one commodity at one terminal. Without a terminal, the assistant offers named choices. Charts preserve missing quotes as gaps and disclose sparse data; they never plot minimum/average/maximum summaries as a time series.

| Example Query | What It Does |
|---|---|
| `Price history of Agricium` | Named terminal choices for historical reports |
| `Price history of Laranite at TDD - Trade and Development Division - Area 18` | Dated buy/sell chart and report table |
| `Laranite history at TDD - Trade and Development Division - Area 18 patch 4.10.0 from 2026-09-01 to 2026-09-25` | Terminal, patch, and date-scoped observations |

### Commodity Info
Search for a commodity to see detailed info with buy/sell tables.

| Example Query | What It Does |
|---|---|
| `Tell me about Laranite` | Type, avg prices, tags + buy/sell location tables |
| `What is Bexalite?` | Commodity details with live pricing data |

## Location Features

### Mining Locations
Look up general locations where UEX records an ore or mineral, or list the ores recorded at a location. Queries can filter by star system, planet, moon, Lagrange region, or point of interest.

| Example Query | What It Does |
|---|---|
| `Where can I mine Laranite?` | General locations associated with Laranite in UEX occurrence mappings |
| `Which ores are found on Hurston?` | Ores with occurrence records on Hurston |
| `Where can I mine Laranite in Stanton?` | Occurrence locations filtered to the Stanton system |
| `Which ores are found on Aberdeen?` | Occurrence records filtered to a moon |

Mining support covers location lookup only. UEX occurrence mappings do not provide coordinates, abundance, or guaranteed spawns, and an unlisted ore or location may still occur in-game. These answers do not determine mining methods, equipment requirements, or mining profits.

## UI Features

### Chat Experience
- **Streaming responses** — Text appears word by word with cursor animation
- **LLM-native responses** — GPT-4o-mini generates natural, conversational answers from structured data (with template fallback)
- **Conversation memory** — Follow-up questions understand context (e.g., "What about in Pyro?" after asking about a commodity)
- **@ mentions with typeahead** — Type `@` to search commodities, ships, locations, and terminals inline
- **Keyboard shortcuts** — `Enter` to send, `Shift+Enter` for newline, `↑` to recall previous message

### Data Display
- **Sortable tables** — Click any column header to sort ascending/descending (numeric-aware sorting)
- **CSV export** — Download any table as a CSV file for spreadsheet use
- **UEX links** — Commodity and terminal names in tables link directly to their UEX Corp pages
- **Price charts** — Interactive line charts for price history (Recharts)

### Continuous Chat
- One ongoing chat resumes after reload; no sidebar or new-chat workflow.
- The latest former conversation becomes the ongoing chat. The old archive remains in browser storage.
- Fresh questions stand alone. Explicit follow-ups such as "Where can I buy it?" can retain context.
- No selected fleet ship is attached to questions.
- Voice input and spoken answers are planned, not implemented.


## Technical Details

### Stack
- **Frontend**: Next.js 16.3, React 19.3, TypeScript, Tailwind CSS v4
- **UI Components**: base-ui (Button, Popover, Sheet, Tooltip, etc.)
- **Data**: UEX Corp API v2.0 (community-reported Star Citizen market and reference data)
- **Charts**: Recharts
- **LLM**: OpenAI GPT-4o-mini — dual use: intent classification and natural response generation
- **Persistence**: localStorage (ongoing chat, preserved older chat archive, theme)

### API Endpoints
| Endpoint | Method | Description |
|---|---|---|
| `/api/chat/stream` | POST | SSE streaming reference chat |
| `/api/suggest` | GET | Typeahead suggestions for @-mentions |
| `/api/vehicle` | GET | Vehicle lookup by name |
| `/api/cache-status` | GET | Cache age info |
| `/api/cache-status` | DELETE | Clear data cache |

### Query Processing Pipeline
```
User message
  → LLM classifier (GPT-4o-mini, with circuit breaker)
  → Keyword parser fallback
  → Context resolver (conversation history)
  → Lazy full-geography resolution and location validation
  → Answer builder (data fetch + handler)
  → Response generator (LLM-native text + fallback)
  → SSE stream (word-by-word with 15ms delay)
```

## API data coverage and reference limits

### Equipment shopping and comparisons

Mining laser heads, mining modules, gadgets, scraper modules, salvage beams, ship components, weapons, and armor are available through UEX categories. Broad searches ask for a more specific category; ambiguous names offer exact choices. Item specifications and shop prices show their source patch separately because equipment attributes can lag current balance changes.

| Example query | Result |
|---|---|
| `Show mining lasers` | Catalogue with manufacturer, size, and source patch |
| `Show scraper modules` | Scraper catalogue and reported extraction efficiency, speed, radius, volume, and specification dates |
| `Tell me about Abrade` | Scraper attributes and purchase locations |
| `Compare Abrade vs Trawler` | Scraper specifications and prices side by side |
| `Where can I buy Cinch scraper modules?` | Reported shops and prices |
| `Show salvage beams` | Separate UEX salvage-beam catalogue |
| `Where can I buy Lancet MH2?` | Shops, per-item prices, report dates, and patches |
| `Compare Lancet MH2 vs Arbor MH1` | Attribute and price comparison with units |
| `Where can I buy Lancet MH2 in Orison?` | Shops filtered to the requested city |
| `Tell me about quantum drive Atlas` | Specific component details and sellers |

### Market alerts and report freshness

`Latest market alerts in Stanton` or `Market alerts for Laranite` shows up to 25 matching feed records with timestamps and stock states. Alerts describe reported states; they do not invent price-change amounts or reasons when UEX supplies no before/after values. An empty feed does not establish an unchanged market.

Price responses show actual report times and source game versions where available, flag reports over 24 hours old, and compare known patches with UEX's LIVE version. Unknown metadata remains unknown. The toolbar’s reference-cache age describes the app’s fetch time, not report freshness. Manual refresh clears application caches and invalidates the framework’s tagged UEX cache.

### Reference scope and limits

Route rankings, budget-based suggestions, fleet recommendations, multi-stop planning and projected-profit answers are disabled. Requests for those features redirect to supported reference lookups.

Commodity answers show reported prices and distinguish forecast demand from terminal inventory. Those reports do not guarantee availability when a player arrives. Ship profiles preserve crew ranges and reported logistics. Commodity flags disclose volatility, explosive cargo and known issues without inventing safe timers. Refinery capacity retains neutral units because UEX's documentation does not establish an SCU interpretation.

### Expanded geography

General lookups and typed suggestions use the full planet, moon, orbit, and point-of-interest catalogues. `Tell me about Pyro Asteroid Clusters` shows reported facility/navigation flags, related terminals, and explicitly mapped mining commodities. General location filters also support cities and stations for equipment and ship prices. Unknown locations never broaden a filtered request into worldwide results.

Scraper lookups accept both `scraper` and `scrapper`, plus `salvage modules`. Abrade, Cinch, Trawler, and ReadyGrip names resolve directly. UEX lists ReadyGrip in the Scraper Beams category; missing extraction properties remain unreported. Specification dates and item patches may be older than shop prices; extraction-speed values retain the source format and do not imply an unstated unit.

## Crafting and mission references

The Star Citizen Wiki game-data API supplies base crafting recipes, blueprint unlock missions, and named mission details. Ask for ingredient quantities and quality, mission reward pools, standing requirements, or immediate prerequisite missions. Source links and game patches are displayed. Matching tolerates punctuation such as XL1/XL-1 and the spoken “XL one.” Explicit blueprint follow-ups retain the referenced item; fresh item questions stand alone. Variants with identical reported requirements are grouped. API results are cached for one hour with bounded request concurrency and storage. SCMDB is not integrated.
